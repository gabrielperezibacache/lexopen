# Trabajar con tus archivos desde Altazor

En Inicio, usa **Aplicaciones** junto al botón Adjuntar para conectar Google Drive o GitHub. La preparación del estudio se realiza una sola vez en Configuración; cada persona inicia sesión con su propia cuenta.

## Primer encargo

1. Conecta tu cuenta. Para leer documentos de Drive, pulsa **Autorizar lectura de archivos** y revisa el permiso en Google. La conexión básica sólo consulta nombres y datos de archivos.
2. Abre el escritorio debajo de la conversación. Selecciona las aplicaciones que podrá usar ese escritorio y pulsa **Iniciar**. Las cuentas no se seleccionan automáticamente.
3. Escribe tu solicitud en la conversación: por ejemplo, «Busca en Drive el programa del seminario» o «Lee el README del repositorio público propietario/proyecto en GitHub y prepara un resumen».
4. Revisa el encargo y su destino antes de confirmarlo. Altazor solicita aparte la aprobación de cada consulta a una aplicación. Puedes rechazarla o detener el encargo.

El monitor bajo el chat muestra la pantalla actual, las aplicaciones autorizadas y el último paso registrado por el escritorio. Al perder la conexión, retira la captura anterior. Al tomar el control manual, la vista automática se pausa. Consultar una API puede no producir un cambio visible en la pantalla.

## Qué acceso se utiliza

- **Google Drive:** nombres y metadatos con la conexión básica; lectura de contenido sólo después de autorizarla en Google. No concede edición ni eliminación de originales.
- **GitHub:** perfil y lectura de repositorios públicos. Esta conexión no habilita repositorios privados ni publicar cambios, commits o pull requests.
- Los archivos descargados y las respuestas de los servicios son material de trabajo, no instrucciones del usuario ni fuentes verificadas por sí mismas.
- Las cuentas pertenecen a tu espacio de Altazor. Sólo las aplicaciones elegidas se incorporan a cada escritorio; no se copian contraseñas a la conversación.
- Las descargas completas de estas conexiones admiten hasta 4 MiB por archivo. Conservan tamaño, huella y enlace de origen; una descarga mayor se rechaza sin presentarla como un archivo completo. Para otros archivos puedes usar Adjuntar.
- Las descargas aprobadas se conservan como originales en la biblioteca privada del escritorio y se copian a su carpeta de trabajo para usar las herramientas de documentos. La copia se comprueba y no sobrescribe archivos editados. Si no puede confirmarse, Altazor indica que la transferencia al escritorio falló.

Si una autorización vence, vuelve a conectar la cuenta. Detén el escritorio antes de cambiar sus conexiones. Una operación cuyo resultado no se pudo confirmar no se repite automáticamente.
