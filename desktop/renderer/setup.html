Servidor del estudio o acceso remoto

Un PC principal guarda usuarios y datos. El resto se conecta por Tailscale a esa misma instalación.

Carpeta de datos

Elija una carpeta vacía existente o los datos de una instalación anterior. No se moverán ni copiarán archivos automáticamente.

Escritorio de Altazor

Comprueba si este equipo puede abrir el escritorio con sus herramientas de oficina, PDF, OCR y audio.

La descarga y la instalación se confirman por separado. Las versiones de prueba pueden tener funciones pendientes de verificar.

En el Host: instale Tailscale y comparta el hostname MagicDNS, o ejecute tailscale serve --bg 3000.

Datos del Host (se conservan al actualizar):

El secreto de sesión se genera una vez en .env y no se regenera en actualizaciones. Puede editarlo en la carpeta de datos.
